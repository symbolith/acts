## Skills

Until acts replace them, skills live in the repository acts, the single home of ALL skills on this system. Dotfiles holds none.

- `file:./acts/.claude-plugin/marketplace.json:1:1` makes acts the Claude Code plugin marketplace `acts`.
- `file:./acts/plugins/:1:1` holds one folder per plugin: `claude-code`, `dev`, `diagrams`, `exogram`, `factors`, `writing`. Skills sit in `<plugin>/skills/<name>/SKILL.md`.
- The user settings register the marketplace as a local directory (`extraKnownMarketplaces`); a fresh clone runs `claude plugin marketplace add ./acts`. Claude Code loads each plugin in place, never from the cache. An edit takes effect at the next session start or on `/reload-plugins`; no commit, no `claude plugin update`.
- Global plugins are enabled in the user settings (`enabledPlugins`): `claude-code`, `dev`, `diagrams`, `exogram`, `writing`. `factors` is enabled only in `file:./factors/.claude/settings.json:1:1`, which `just init` writes. A new plugin needs an entry in `marketplace.json` and in `enabledPlugins`.
- Plugin skills are invoked with a prefix, e.g. `/dev:write-rust`.
- A plugin skill runs from any working directory. Reference files by absolute path, never `./`.

# Trusted Sources by Category

Sources that are independent, transparent about methodology, or community-driven. Not exhaustive — use as starting points, not whitelists.

## Independent reviewers (no/limited affiliate)

- **Wirecutter** (NYT) — long-form testing, discloses affiliate but has editorial wall
- **Consumer Reports** — nonprofit, no advertising, buys all products it tests
- **RTINGS.com** — owned-and-operated lab tests for displays, audio, peripherals
- **iFixit** — repairability, teardowns
- **Project Farm** (YouTube) — tools, lubricants, consumables, controlled tests
- **DPReview** — cameras (archive era especially good)
- **AnandTech** archive — deep hardware reviews (site is winding down, archive still useful)
- **Tom's Hardware** Labs reviews (skip the listicles)
- **Phoronix** — Linux hardware/software benchmarks
- **Ars Technica** — long-form tech journalism

## Community discussion

- **Reddit** — niche subreddits are gold, default subs are noisy. Look for sticky FAQs and "what did you buy" threads.
- **Hacker News** — best for software, infrastructure, startups, research papers
- **Lobsters** — smaller, more technical than HN
- **Stack Exchange network** — high-quality Q&A across many domains
- **Discourse forums** — many open source projects host their own (e.g. discuss.python.org)
- **Mastodon/Fediverse** — search via `https://tootfinder.ch/` or instance-specific search

## Primary technical sources

- **Project README + docs** on the official repo
- **arXiv** for ML/CV/NLP/physics papers
- **Google Scholar** with "cited by" navigation
- **Semantic Scholar** — better filtering than Scholar for some fields
- **ACM Digital Library**, **IEEE Xplore** (paywalled but abstracts visible)
- **RFC Editor** for internet standards
- **W3C** for web standards
- **NIST** for measurement, security baselines
- **MDN Web Docs** for web platform reference

## Reference / encyclopedic

- **Wikipedia** — neutral overview, follow the citations at the bottom
- **Wikiwand** — same content, better reading
- **Stanford Encyclopedia of Philosophy**
- **Internet Archive / Wayback Machine**

## Domain-specific gems

### Software / programming
- `lib.rs`, `crates.io` (Rust)
- `pypi.org`, `pythontest.com`, `realpython.com` (Python)
- `npmjs.com`, but cross-check with GitHub stars + recent commits
- `awesome-*` lists on GitHub (curated, but check freshness)

### Hardware / DIY
- `r/BuildaPC`, `r/buildapcsales`
- `Logical Increments`
- `PCPartPicker` build guides

### Art / design / installation
- `Creative Applications Network` — interactive/installation art
- `We Make Money Not Art`
- `r/installationart`, `r/generative`
- ArtStation forums (concept art workflow)
- Studio websites of practicing artists (look at their "process" pages)
- Museum/festival archives (Ars Electronica, transmediale, ZKM)

### Science
- `arxiv.org`, `biorxiv.org`, `medrxiv.org` (preprints, with caveats)
- `pubmed.gov`
- Cochrane Reviews for medical meta-analyses

### Photography / cameras
- DPReview archive
- `r/photography`, `r/AskPhotography`
- `petapixel.com` news
- Photons to Photos sensor measurements

### Audio
- `Audio Science Review` — measurements, no marketing
- `r/audiophile` (with skepticism), `r/headphones`
- Crinacle's IEM measurements

## Sources for product-specific signals

These help with **freshness and trust checks** in product research mode.

### Is this product still alive / maintained?
- GitHub commit activity, release cadence, open-vs-closed issue ratio
- Project blog / changelog dates
- `<product> site:reddit.com after:<6mo>` and `<product> site:news.ycombinator.com after:<6mo>`
- Mastodon/Bluesky search for the project handle
- `web.archive.org` to compare the homepage now vs 12 months ago

### Has this product been enshittified recently?
- `r/<product>` and `r/<product>Sucks` if either exists
- `<product> "killed free tier"`, `<product> "price increase"`, `<product> "got worse"`
- `site:trustpilot.com <product>` — read detailed negative reviews, ignore star average
- `<product> layoffs site:news.ycombinator.com`
- `<product> acquired` / `<product> shutdown`

### Discovery (use to find candidates, never as quality signal)
- ProductHunt — launch-day hype
- G2, Capterra, TrustRadius, Software Advice — gift-card-incentivized reviews
- "AI tools directory" sites — affiliate plays
- AlternativeTo — useful for finding competitors of a known product

## How to vet a new "trusted" source

Check:
1. **Methodology page** — do they explain how they test?
2. **Author bios** — real names, real backgrounds
3. **Date stamps** — recent updates, not just "Last updated 2026" boilerplate
4. **Affiliate disclosure** — present and specific, or hidden?
5. **Comments/discussion** — do critics get answered?
6. **Negative reviews** — do they ever say a product is bad?
7. **Cross-domain consistency** — does the site recommend across all categories with the same enthusiasm? (red flag)
